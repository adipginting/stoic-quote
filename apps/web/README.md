# Stoic Quote Web

TanStack Start site for the Stoic Quote API: one quote at a time, with imagery, explanations and favourites.

## Running

```bash
pnpm --filter @stoic-quote/web dev     # http://localhost:3001
```

Server functions call the API server-side; point them elsewhere with `API_URL` (default `http://localhost:3000`). Start the API first (`pnpm --filter @stoic-quote/api dev`), or run both with `pnpm dev` from the repo root.

## Routes

- `/` — deterministic daily quote plus "New quote" random fetch
- `/q/$id` — deep link for a single quote (shareable; `og:image` from the quote's Unsplash photo)
- `/favourites` — the visitor's saved quotes (anonymous, stored per browser via `localStorage` id)

Actions: New quote, Explain (DeepSeek, shown only when the API reports it is configured), Save (favourites), Share (native share or copy link).

## Build

```bash
pnpm --filter @stoic-quote/web build          # → .output (Nitro)
pnpm --filter @stoic-quote/web check-types
node .output/server/index.mjs                 # production server, PORT=3000
```

Styling is Tailwind CSS v4 via `@tailwindcss/vite`; the CSS entry is `src/styles.css`. Routing is file-based under `src/routes` — `src/routeTree.gen.ts` is generated by the Vite plugin on dev/build and is committed.

## Observability

`src/server.ts` (the custom Start server entry) initialises OpenTelemetry
before the app loads, and `src/lib/logger.server.ts` is the pino logger used by
the server-only API client. Both are inert unless `OTEL_EXPORTER_OTLP_ENDPOINT`
is set; when enabled, outbound calls propagate W3C `traceparent` so web→api
requests share one trace.

Photos are displayed from Unsplash (`images.unsplash.com`, hotlinked per their guidelines) with photographer credit; all texts are public-domain translations from Standard Ebooks.
